# Residual Controllers

This repository contains the public paper PDF and data artifacts for the
residual-controller reasoning-switch experiments.

## Contents

- `paper/main.pdf`: paper PDF only; LaTeX sources are intentionally not included.
- `artifacts/`: JSON, Markdown, and logged result artifacts used by the paper.

The development repository and paper source are not vendored here. This repo is
intended as a lightweight public artifact mirror for reading the paper and
inspecting the underlying result files.
